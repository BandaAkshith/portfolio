# Akshith Krishna Banda Portfolio

A minimal static portfolio site for Akshith Krishna Banda, built with plain HTML, CSS, and JavaScript. It is ready to host on GitHub Pages without a build step.

## Features

- Responsive one-page portfolio layout
- Minimal light and dark themes using CSS variables
- Accessible keyboard-friendly navigation
- Simple text-first layout with no image assets
- Active navigation states

## Files

- `index.html` - page structure and portfolio content
- `styles.css` - responsive visual design and theme tokens
- `script.js` - theme state, navigation, and active section state
