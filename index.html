Projects

Selected Work

2024

Vision3D - NeRF-Based 3D Reconstruction

Developed an end-to-end web application that reconstructs 3D objects and scenes from multiple 2D images using NeRF, Instant-NGP, and Nerfstudio-based training pipelines.

Implemented image upload, preprocessing, background removal, GPU-based training with ns-train nerfacto, 3D model generation, and interactive visualization with rotation, zoom, and pan controls using React and Material UI.

2024

Underwater Image Super-Resolution Using ESRGAN and SR3

Designed an underwater image restoration and super-resolution pipeline combining color correction and dehazing with Real-ESRGAN and SR3 diffusion-based super-resolution to recover fine-grained details.

Prepared high-resolution and low-resolution image pairs from the UIEB, EUVP, and UFO120 datasets, and applied pretrained PyTorch models to address low contrast, color distortion, haze, and lost high-frequency details.

2024

Retrieval-Augmented Question Answering System

Built a retrieval-augmented question answering system with Python, Hugging Face, Sentence Transformers, Pinecone, and the OpenAI API using the SQuAD dataset.

Generated embeddings with all-MiniLM-L6-v2, indexed them for efficient semantic retrieval, and generated context-aware answers grounded in the indexed knowledge base.

2024

Real-Time Sign Language Detection System

Developed a real-time sign language recognition system using Python, PyTorch, OpenCV, and MediaPipe to detect and classify hand gestures from video streams and camera input.

Implemented MediaPipe hand landmark extraction and OpenCV preprocessing to generate model-ready features, then trained and evaluated a PyTorch model with the WLASL dataset for end-to-end real-time prediction.
